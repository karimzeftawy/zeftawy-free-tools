Clean CSV exports safely without Pandas

Real CSV exports contain leading whitespace, all-blank records, quoted commas and sometimes a UTF-8 byte-order mark.

Use a parser, not split()

A naive line.split(",") breaks data such as "New York, NY". Python's standard csv module understands quoting. utf-8-sig gracefully handles BOM-encoded files.

import csv
with open("input.csv", encoding="utf-8-sig", newline="") as src:
    for row in csv.reader(src):
        cleaned = [cell.strip() for cell in row]
        if cleaned and any(cleaned):
            print(cleaned)

Never overwrite the original

Open a different output file in exclusive-create mode "x" to avoid overwriting existing work. Keep duplicates unless you explicitly intend to remove repeated records; identical rows can reflect valid separate events.

with open("input.csv", encoding="utf-8-sig", newline="") as src:
    with open("output.csv", "x", encoding="utf-8", newline="") as dst:
        writer = csv.writer(dst)
        for row in csv.reader(src):
            row = [item.strip() for item in row]
            if row and any(row):
                writer.writerow(row)
Simple cleanup cannot repair malformed CSV, sanitize spreadsheet formulas or infer types. Test on sample data before processing important records.
