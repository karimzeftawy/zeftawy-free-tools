Exactly what gets cleaned?

All nonempty cell values are trimmed at the beginning and end. Rows where every cell is blank are removed. Original header capitalization and repeated rows are preserved. Commas inside quoted fields and escaped quotation marks are handled correctly. Output is UTF-8 CSV using normal CSV quoting.

The cleaner does not deduplicate, fix malformed data, infer column types, or validate spreadsheet formulas. Test on a sample first.

Common questions

Does it upload my CSV?

No. JavaScript inside your browser does the parsing, cleaning and downloading. No analytics or external scripts are included on this page.

Can it clean Excel .xlsx?

No. Export the Excel sheet as UTF-8 CSV first. This tool accepts CSV text only.

Will it remove duplicate records?

No. Identical rows are kept on purpose; you can decide separately if deduplication makes sense for your dataset.

Does it handle commas within quotes?

Yes, valid quoted CSV fields are parsed correctly. Malformed quote sequences are rejected with an error.
